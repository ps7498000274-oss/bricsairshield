# BRICS AirShield — 4 minute demo script

**0:00 Problem (25s)** — Pollution monitoring is national and coarse. Localised events are missed, and cross-border pollution becomes invisible when every country publishes a different index.

**0:25 Overview `/`** — 26 cities, five BRICS nations, one comparable risk index. Point at the global risk index, hotspot count and the alert banner. Filter to India, then back to All BRICS. Note the demo-data label.

**1:00 Live intelligence `/live`** — Open the worst hotspot. Show the factor breakdown: PM2.5, dispersion, inversion — every point traceable. Click "Explain risk": Google Gemini explains it in plain language for an official.

**1:45 Photo analyzer `/analyze`** — Upload a smoke photo. Gemini returns structured JSON: type, severity, confidence, indicators, likely sources, action. Show the sensor-only risk vs the fused risk.

**2:30 Report `/report`** — Submit the same evidence as an incident. Pipeline runs live: Gemini analysis → risk scoring → incident ID → alert at ≥75 → Gemini incident brief for triage.

**3:00 Copilot `/copilot`** — "Which BRICS countries have the most high-risk locations?" then "How can AirShield scale to Brazil?" Grounded on real app context; it refuses data it wasn't given.

**3:30 Countries `/countries`** — Identical method applied to every country, so comparison is meaningful. Adding a sixth country is a dataset append.

**3:50 Close** — Honest by design: `/methodology` states what is simulated, what is real, and what the system cannot do. Runs entirely on free tiers.
